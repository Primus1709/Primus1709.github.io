# Pratham Poptani Portfolio

A simple static portfolio built with plain HTML, CSS, and JavaScript.

## Edit before publishing

Open `index.html` and replace:

- `your-email@example.com`
- The LinkedIn placeholder URL
- Project descriptions/links as your work develops

## Run locally

You can simply open `index.html` in your browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Put these files in the repository root.
3. Push to GitHub.
4. In GitHub: **Settings → Pages**.
5. Set the deployment source to your main branch/root.
6. Add your custom domain: `prathampoptani.com`.

If your domain is managed through Namecheap, add the DNS records GitHub Pages gives you.
