## About

This site is a simple, fast, static portfolio built to showcase my projects, technical interests, and current work.

I prefer building things that help me understand systems deeply — whether that means learning algorithms through graph tooling, working with Linux and automation, or shipping small products that solve real problems.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Primus1709/Primus1709.github.io.git
cd Primus1709.github.io
```

You can open `index.html` directly in your browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
